# Notes & Systems

Personal website built with AstroPaper and Astro.

Website: https://chenyeum.github.io/

## Stack

- Astro
- AstroPaper
- Markdown and MDX
- GitHub Pages
- GitHub Actions
- Pagefind

## Local Development

```bash
pnpm install
pnpm dev
```

## New Article

```bash
pnpm new:post tech "My New Article"
```

## Production Build

```bash
pnpm build
pnpm preview
```

## Content

- Tech
- Research
- Reading
- Life
